# Ethermind — Application Source Code

This directory contains the Next.js 16 source code for the **Ethermind Agency** web platform.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Configure environment variables in .env.local
# GEMINI_API_KEY=...
# GMAIL_USER=...
# GMAIL_APP_PASSWORD=...

# Run dev server
npm run dev

# Build production bundle
npm run build
```

See the root [README.md](../README.md) for complete technical architecture and documentation.
